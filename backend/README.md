# NewChapter Bot - Інструкція зі старту

1. Переконайся що встановлений Go версії 1.21 або новіший.
2. Додай файл credentials.json у папку backend.
3. Відкрий папку backend у VS Code.
4. Відкрий термінал у VS Code (Terminal → New Terminal).
5. У терміналі напиши:

```bash
go mod tidy
go run main.go
